# Dual reference: design and performance contract

The existing system diagram remains the center of the human view. The agent view routes from a small map to a topic card and then an exact source record. Both derive from the same captured corpus and stable section IDs. Human pages do not load the complete corpus until search is requested.

Visual direction: a PS1 hardware reference wearing Zero-inspired red armor. Use oxblood `#641c32`, candy red `#a9203e`, porcelain `#eee9e7`, gunmetal `#20232b`, pearl white `#fffaf5`, and restrained jade `#286351` for diagrams and hardware status. A narrow pearlescent strip runs through the header; beveled red panel edges and console-button geometry carry the retro character. Keep reading surfaces calm and tables fixed-width. The existing map retains its node positions, wiring and green signal language.

Use locally available Bahnschrift for condensed display and interface type, Segoe UI for long reading, and Consolas for source data. No font downloads. Attributions and snapshot provenance are consolidated into the existing sidebar block with expandable details; original source credits remain in the articles. The default theme is pearl, with a gunmetal alternate.

Do not add character art, distracting motion, CRT blur or scanlines across text. The red/pearl panel treatment is the memorable element; diagram legibility and fast retrieval take priority.

Baseline (three fresh offline browser contexts): page load 317–352 ms, first DMA2 search 1,566–1,957 ms. Every initial page loaded a 15,610,369-byte corpus script. Measured by the same benchmark used after optimization; timings are local synthetic results, not universal guarantees.
